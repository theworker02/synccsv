# synccsv

Sync CSV/TSV csv tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/synccsv/

## Install / run

```bash
git clone https://github.com/theworker02/synccsv.git
cd synccsv
node src/cli.js
node --test
```
